# Built-in cupboard photos go here

Drop any photo file in this folder (jpg, jpeg, png, or webp) — any filename
works, no renaming needed. It'll be picked up automatically the next time
the dev server starts (restart it if a newly-added photo doesn't appear).

Once there's at least one photo here, the Home page's "Built-in cupboards"
section and the Projects gallery both switch from the placeholder frame to
a real photo grid automatically.

To improve a photo's caption (otherwise it just uses the filename), add an
entry in `../../../data/photo-meta.js` — see that file for the format.

This file itself isn't a photo, so it's ignored.
