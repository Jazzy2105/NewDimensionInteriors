# Kitchen photos

The ten `kitchen-NN.jpg` files are the original client photos (captioned and
curated in `../../../data/photo-meta.js`). Drop more photos in here the same
way — any filename works, no renaming needed — and they'll appear in the
Projects gallery automatically, with no caption chip until you add one in
`photo-meta.js` (a raw filename isn't shown as-is). Mark a photo
`featured: true` (and/or `hero: true`) there if you want it picked for the
Home page preview grid or the homepage hero carousel too.

This file itself isn't a photo, so it's ignored.
