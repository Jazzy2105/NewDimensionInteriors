# Kitchen photos

The ten `kitchen-NN.jpg` files are the original client photos (captioned and
curated in `../../../data/photo-meta.js`). Drop more photos in here the same
way — any filename works, no renaming needed — and they'll appear in the
Projects gallery automatically. Mark a photo `featured: true` (and/or
`hero: true`) in `photo-meta.js` if you want it picked for the Home page
preview grid or the homepage hero carousel too; otherwise the busiest/newest
photos just fill in the gallery without needing any of that.

This file itself isn't a photo, so it's ignored.
